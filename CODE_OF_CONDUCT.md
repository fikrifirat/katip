# Code of conduct

Katip adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone who takes part: in issues, pull requests, discussions, and at events
where Katip is presented.

In short: be kind and patient, assume good intent, welcome people new to open source and to law, and
criticise work, not people. Harassment, insults and publishing someone's private information are not
accepted. For a project about personal data, that last one counts double: never post anyone's real
personal data, including your clients', anywhere in this project.

## Reporting

Write to **fikrifirat@gmail.com** with "Katip conduct" in the subject. Reports are read by the maintainer and
kept confidential. If the report is about the maintainer, say so in the subject and it will be handled with an
outside reviewer.

Enforcement follows the Contributor Covenant's guidelines: a correction, a warning, a temporary ban or a
permanent ban, depending on what happened.
